# Host Auth Badges

**Русский** · [English](README.md)

Показывает рядом с каждым хостом в списке [Termix](https://github.com/Termix-SSH/Termix) два коротких настраиваемых бейджа. Работает для SSH-хостов и для хостов с другим протоколом, например RDP.

- **SOURCE**: откуда берётся вход. `CRED` (сохранённый credential), `HOST` (задан в хосте), `EXT` (плагин аутентификации), `?` (неизвестно).
- **METHOD**: как выполняется вход. `PASS`, `KEY`, `BOTH`, `AGENT`, `NONE`, `OTHER`, `?`.

Бейджи лишь показывают то, что сообщает Termix. Они не проверяют вход, не читают секреты и не оценивают безопасность. Плагин запрашивает только разрешение `ui:surface`.

## Возможности

- 12 однострочных макетов и 18 палитр.
- Своя иконка, подпись и цвет для каждого значения SOURCE и METHOD, у каждого свой сброс.
- 104 иконки с поиском, размеры текста и иконок, живой предпросмотр.
- Английский и русский интерфейс.

## Установка

В Termix откройте Plugins, найдите Host Auth Badges в community-реестре и установите, затем откройте его настройки. Изменения сразу видны в списке хостов, сохраняет их кнопка **Save** в Termix.

## Настройки

Пользовательские: `enabled`, `position`, `textSize`, `iconSize`, `sourceConfig`, `methodConfig`, `layoutVariant`, `palettePreset`.

Хосты и папки могут переопределять внешний вид тремя полями: `compositionOverride` (макет, палитра, размеры, позиция, enabled), `sourceOverride` и `methodOverride`. Порядок: хост, папка, родительские папки, пользователь, сервер, значения плагина. Изменения хоста или папки доходят до реального списка после Save.

## Как определяется бейдж

- Обычные SSH-хосты берут собственный тип входа хоста или сохранённый credential, на который он указывает, в том числе унаследованный от папки или пользователя.
- Если SSH выключен, берётся вход основного протокола хоста (RDP и подобные).
- У shared-хостов плагин показывает только то, что раскрыл владелец. Неизвестное отображается как `?`.
- Имена credentials, пароли и ключи не сохраняются, учитывается только тип credential.

## Ограничения

- Метод credential, который хранится на другом сервере (копия общего хоста в десктопе), недоступен, поэтому показывается `?`.
- Если SOURCE скрыт, а METHOD показывает только иконку, бейджи могут выглядеть одинаково. Редактор предупреждает об этом.

Нужен Node.js 22.12 или новее.

```bash
npm install
npm test
npm run test:sdk
npm run typecheck
npm run validate
npm run pack
```
