# Host Auth Badges

**Русский** · [English](README.md)

Показывает рядом с SSH-хостами в списке [Termix](https://github.com/Termix-SSH/Termix) два компактных настраиваемых бейджа:

- **SOURCE** показывает, откуда взяты параметры входа: `CRED`, `HOST`, `EXT`, `?`.
- **METHOD** показывает настроенный способ входа: `PASS`, `KEY`, `BOTH`, `AGENT`, `NONE`, `OTHER`, `?`.

Бейджи обобщают конфигурацию аутентификации, о которой сообщает Termix. Они не проверяют вход, не читают SSH-секреты и не оценивают безопасность хоста. Плагин запрашивает только разрешение `ui:surface`.

## Что можно делать

- 12 однострочных макетов и 18 палитр (по умолчанию Unframed и Catppuccin).
- Отдельные иконка, подпись и цвет для каждой категории SOURCE и METHOD, у каждого свой сброс. Сброшенный цвет возвращается к текущей палитре.
- 104 иконки Lucide в семи группах, с поиском. Выбор иконки и бейджи на хостах используют один каталог.
- Независимые размеры текста и иконок (60-220% и 60-260%). Списки и ползунки реагируют на колесо мыши.
- Живой предпросмотр на девяти синтетических хостах. Предпросмотр показывает бейджи, даже если плагин отключён.
- Английский и русский интерфейс.

## Установка

Откройте Plugins в Termix, включите community-реестр (админы), найдите Host Auth Badges и установите. Затем откройте настройки **Host Auth Badges**.

Изменения в пользовательских настройках сразу видны на показанных бейджах хостов через черновик в памяти. Чтобы сохранить их, всё равно нужна штатная кнопка **Save** в Termix; при закрытии без сохранения черновик отбрасывается.

## Настройки

Пользовательские настройки: `enabled`, `position`, `textSize`, `iconSize`, `sourceConfig`, `methodConfig`, `layoutVariant`, `palettePreset` и пользовательский редактор.

Настройки хоста и папки: три независимо наследуемых JSON-поля: `compositionOverride` (макет, палитра, размеры, позиция и enabled), `sourceOverride` и `methodOverride`. Последние два скрыты и редактируются через единый редактор хоста и папки. Порядок наследования: хост, ближайшая папка, родительские папки, пользователь, сервер, затем заводские значения.

Редактор может попросить Termix очистить поле через `setValue(field, null)`: для одной группы или для всех трёх кнопкой **Reset all overrides**; результат всё равно сохраняется через Save. Публичный SDK не описывает это как действие наследования, поэтому проверьте его в своей версии Termix, прежде чем на него полагаться (см. [docs/setup.md](docs/setup.md)). Редактор сравнивает значения с пользовательскими настройками, а не с реальной родительской папкой или сервером.

Правки хоста и папки сразу меняют предпросмотр в редакторе. Бейджи на реальных хостах меняются после Save, когда Termix публикует новые эффективные `pluginSettings`: форма настроек не сообщает, какой хост или папка редактируются.

## Производительность и приватность

- Termix сам решает, какие строки списка смонтированы. Смонтированные бейджи используют один общий `IntersectionObserver` с запасом 160px и отписываются от хранилищ настроек и учётных данных плагина, пока находятся вне экрана.
- Метаданные учётных данных загружаются один раз на аккаунт и обновляются по таймеру, при фокусе и при смене видимости. Сохраняется только `authType`; имена, пароли и ключи не хранятся. Снимки привязаны к аккаунту, поэтому после смены аккаунта данные предыдущего не показываются.
- У плагина нет собственного сетевого доступа, телеметрии, фоновых SSH-соединений и дополнительных разрешений.

## Ограничения

Если SOURCE скрыт, а METHOD показывает только иконку, бейджи на разных хостах могут выглядеть одинаково. Редактор предупреждает об этом сочетании. **Reset appearance** возвращает значения по умолчанию.

## Разработка

Нужен Node.js 22.12 или новее.

```bash
npm install
npm test
npm run test:sdk
npm run typecheck
npm run validate
npm run pack
```

Ключи настроек и идентификаторы иконок стабильны. См. [docs/setup.md](docs/setup.md) и [docs/publishing.md](docs/publishing.md).
